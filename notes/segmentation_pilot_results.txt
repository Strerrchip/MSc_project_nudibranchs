Segmentation pilot results

Purpose:
This note records the first automatic segmentation pilot for the nudibranch image-analysis workflow.

Method tested:
OpenCV GrabCut was tested as a simple baseline method. The script used an automatic central rectangle to initialise GrabCut. The output mask was then cleaned using simple morphological operations. A surrounding background ring was created by dilating the animal mask and subtracting the original animal mask.

Test images:
1. Aphelodoris_varia_img01
2. Aphelodoris_varia_img02
3. Doriprismatica_atromarginata_img01
4. Doriprismatica_atromarginata_img02
5. Doriprismatica_atromarginata_img03

Results:

Aphelodoris_varia_img01:
The segmentation result was good. The mask covered most of the nudibranch. Some small edge details may have been missed, but the result was usable as an initial automated test.

Aphelodoris_varia_img02:
The segmentation result was moderate. The mask captured most of the animal, but also included some nearby background below the animal. This may affect colour and contrast measurements.

Doriprismatica_atromarginata_img01:
The segmentation result was good. The mask captured most of the animal body. Some thin edges were not perfect, but the result was reasonable.

Doriprismatica_atromarginata_img02:
The segmentation result was moderate. The mask captured the central part of the animal, but missed some pale body edges and thin structures.

Doriprismatica_atromarginata_img03:
The segmentation result was weak to moderate. The mask captured part of the animal, but also included too much red background / algae. This shows that GrabCut can struggle with complex backgrounds.

Overall conclusion:
This first automatic segmentation test was useful as a proof of concept. It showed that a Python workflow can automatically produce animal masks, background rings and QC figures. However, the masks are not accurate enough for final analysis.

Main problems:
1. Some masks included nearby background.
2. Some masks missed thin or pale parts of the animal.
3. Complex algae or sponge background was sometimes incorrectly included in the animal mask.
4. GrabCut depended strongly on the animal being mostly central and visually different from the background.

Next step:
The GrabCut workflow can be kept as a simple baseline. A more flexible segmentation method, such as SAM / SAM2 or another Python-based segmentation approach, should be tested and compared with these QC results.

Updated background ring test:

The background ring width was changed from 30 pixels to 80 pixels. The 80-pixel ring looked more useful because it included a larger surrounding background area while still staying close to the animal. This version was kept as the current GrabCut baseline.

Current baseline:
- segmentation method: OpenCV GrabCut
- animal mask: automatic GrabCut mask with simple cleaning
- background definition: 80-pixel ring around the animal
- background ring method: dilated animal mask minus animal mask
- metrics file: processed_data/automated_image_analysis/image_metrics/grabcut_ring80_image_metrics_pilot.csv

Important note:
The GrabCut result is useful as a first automatic baseline, but it is not accurate enough to be the final method. Some masks still include background or miss parts of the animal. The next segmentation method should be compared against this baseline.

SAM segmentation pilot

After testing GrabCut, I tested a SAM-based segmentation method using the ultralytics Python package. SAM generated multiple candidate masks for each image. I then used a simple rule-based scoring method to select the most likely nudibranch mask.

The scoring method was based on:
- mask size
- distance from image centre
- whether the mask touched the image border
- mean brightness
- mean saturation

For the current pale / white pilot species, this worked better than GrabCut. The selected SAM masks were more accurate and the background rings were correctly placed around the animal.

Current SAM workflow:
1. Read image.
2. Generate candidate masks using SAM.
3. Score candidate masks.
4. Select the most likely nudibranch mask.
5. Create background ring by dilating the animal mask and subtracting the animal mask.
6. Save animal mask, background ring and QC figure.

Output folders:
processed_data/automated_image_analysis/masks/sam_pale_score/
processed_data/automated_image_analysis/background_rings/sam_pale_score/
processed_data/automated_image_analysis/qc_figures/sam_pale_score/

Current conclusion:
SAM pale-score segmentation is better than the GrabCut baseline for the pilot images. It is now the current main segmentation method for the automated workflow.

Important limitation:
The current scoring method works well for pale / white nudibranchs in the pilot images. It may need to be adjusted for species with very different colour patterns, such as strongly red, orange, dark or highly saturated species.

Initial interpretation:
In this small pilot set, Doriprismatica atromarginata showed stronger animal-background contrast than Aphelodoris varia. This included higher gray contrast, brightness contrast and Lab colour distance. Its saturation contrast was also more negative, which is consistent with a pale animal against a more saturated red/orange background.

Aphelodoris varia showed higher animal edge density in this pilot. This may reflect stronger internal texture or pattern variation within the animal region.

Important limitation:
This is only a small pilot test. The current values should not be treated as final biological results. The main result is that the SAM-based automated workflow can now segment the animal, generate a background ring, extract image-level metrics and summarise them at species level.

Current conclusion:
SAM pale-score segmentation is the current main automated segmentation method. GrabCut remains useful as a simple baseline, but SAM produced better animal masks for the pilot images.
