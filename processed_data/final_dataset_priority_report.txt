Final dataset priority report
=============================

1. Broad background dataset
---------------------------
D01 Prieto cleaned master table:
File: master_table_v1.csv
Shape: (90, 7)
Role: Broad background table for prey group, chemical acquisition, and colour pattern.

2. Detailed chemical defence dataset
------------------------------------
D03 Table_S1 species summary:
File: table_s1_species_summary.csv
Shape: (30, 15)
Role: Species-level chemical defence, toxicity, and unpalatability information.

3. Detailed colour metrics dataset
----------------------------------
D04 colour_defence_2024 species metrics summary:
File: colour_defence_2024_species_metrics_summary.csv
Shape: (47, 165)
Role: Large species-level colour, luminance, and visual pattern metrics dataset.

4. D05 combined dataset
-----------------------
D05 combined species summary:
File: d05_combined_species_summary.csv
Shape: (13, 329)
Role: Boldness, detection, and unpal shrimp data.

5. D06 habitat background dataset
---------------------------------
D06 habitat background species metrics summary:
File: d06_habitat_background_species_metrics_summary.csv
Shape: (12, 165)
Role: Habitat background, palatability, toxicity, and visual metrics.

6. Main candidate combined datasets
-----------------------------------

Candidate A: D03 + D05
File: chemical_defence_d05_boldness_detection_matched_species.csv
Shape: (11, 343)
Species:
['Aphelodoris varia', 'Chromodoris elisabethina', 'Chromodoris kuiteri', 'Doriprismatica atromarginata', 'Goniobranchus collingwoodi', 'Goniobranchus splendidus', 'Hypselodoris bennetti', 'Phyllidia elegans', 'Phyllidia ocellata', 'Phyllidia varicosa', 'Phyllidiella pustulosa']
Role: Strongest main candidate dataset because it has 11 matched species.

Candidate B: D05 + D06
File: d05_d06_matched_species_summary.csv
Shape: (10, 493)
Species:
['Aphelodoris varia', 'Chromodoris elisabethina', 'Chromodoris kuiteri', 'Discodoris sp', 'Doriprismatica atromarginata', 'Glossodoris vespa', 'Hypselodoris bennetti', 'Phyllidia ocellata', 'Phyllidia varicosa', 'Phyllidiella pustulosa']
Role: Strong exploratory dataset linking boldness/detection with habitat background variables.

Candidate C: D03 + D05 + D06
File: core_d03_d05_d06_matched_species.csv
Shape: (8, 507)
Species:
['Aphelodoris varia', 'Chromodoris elisabethina', 'Chromodoris kuiteri', 'Doriprismatica atromarginata', 'Hypselodoris bennetti', 'Phyllidia ocellata', 'Phyllidia varicosa', 'Phyllidiella pustulosa']
Role: Most complete core dataset, but only 8 species.

Candidate D: D03 + D04 + D05
File: core_d03_d04_d05_matched_species.csv
Shape: (5, 507)
Species:
['Aphelodoris varia', 'Doriprismatica atromarginata', 'Goniobranchus collingwoodi', 'Goniobranchus splendidus', 'Hypselodoris bennetti']
Role: Very complete but small; likely supplementary only.

7. Current recommendation
-------------------------
Use D03 + D05 as the main candidate analysis dataset.
Use D03 + D05 + D06 as a stricter core exploratory dataset.
Use D01 Prieto as broad contextual/background information rather than forcing all datasets into it.
D04 is useful as a large colour metrics dataset, but overlap with the chemical defence datasets is limited.
